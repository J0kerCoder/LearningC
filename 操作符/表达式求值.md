| 操作符 | 描述 | 用法示例 | 结果类型 | 结合性 | 是否控制求值顺序 |
|---|---|---|---|---|---|
| `()` | 函数调用 | `func(a, b)` | 函数声明指定的返回类型 | 左到右 | 否；实参之间的求值顺序未规定 |
| `[]` | 数组下标 | `arr[i]` | 元素类型的左值 | 左到右 | 否；`arr` 和 `i` 的求值顺序未规定 |
| `.`、`->` | 访问结构体或联合体成员 | `person.age`、`ptr->age` | 成员声明指定的类型 | 左到右 | 否 |
| `x++`、`x--` | 后置自增、自减 | `i++` | `x` 的类型；结果不是左值 | 左到右 | 否；副作用在前一个完整表达式结束前完成 |
| `++x`、`--x` | 前置自增、自减 | `++i` | `x` 的类型；结果不是左值 | 右到左 | 否 |
| `+`、`-` | 一元正号、负号 | `-x` | 整数提升后的类型，或操作数类型 | 右到左 | 否 |
| `!` | 逻辑非 | `!x` | `int`，结果为 `0` 或 `1` | 右到左 | 否 |
| `~` | 按位取反 | `~x` | 整数提升后的类型 | 右到左 | 否 |
| `*`（一元） | 解引用 | `*ptr` | 指向对象类型的左值 | 右到左 | 否 |
| `&`（一元） | 取地址 | `&x` | 指向操作数类型的指针 | 右到左 | 否 |
| `sizeof` | 求类型或对象的大小 | `sizeof(int)`、`sizeof x` | `size_t` | 右到左 | 通常是；操作数一般不求值，变长数组除外 |
| `(类型名)` | 强制类型转换 | `(double)x` | 指定的类型 | 右到左 | 否 |
| `*`、`/`、`%` | 乘法、除法、取余 | `a * b`、`a % b` | 常规算术转换后的类型 | 左到右 | 否；左右操作数求值顺序未规定 |
| `+`、`-`（二元） | 加法、减法 | `a + b` | 常规算术转换后的类型，指针运算时为指针或整数 | 左到右 | 否 |
| `<<`、`>>` | 左移、右移 | `x << n` | 整数提升后的类型 | 左到右 | 否 |
| `<`、`<=`、`>`、`>=` | 关系比较 | `a < b` | `int`，结果为 `0` 或 `1` | 左到右 | 否 |
| `==`、`!=` | 相等、不等比较 | `a == b` | `int`，结果为 `0` 或 `1` | 左到右 | 否 |
| `&`（二元） | 按位与 | `a & b` | 整数提升和通常算术转换后的类型 | 左到右 | 否 |
| `^` | 按位异或 | `a ^ b` | 整数提升和通常算术转换后的类型 | 左到右 | 否 |
| `\|` | 按位或 | `a \| b` | 整数提升和通常算术转换后的类型 | 左到右 | 否 |
| `&&` | 逻辑与，短路求值 | `a && b` | `int`，结果为 `0` 或 `1` | 左到右 | 是；仅当 `a` 非 `0` 时求值 `b` |
| `\|\|` | 逻辑或，短路求值 | `a \|\| b` | `int`，结果为 `0` 或 `1` | 左到右 | 是；仅当 `a` 为 `0` 时求值 `b` |
| `?:` | 条件运算符 | `a ? b : c` | 由 `b` 和 `c` 的类型共同决定 | 右到左 | 是；只求值 `b` 或 `c` 中的一个 |
| `=`、`+=`、`-=`、`*=`、`/=`、`%=` | 赋值及复合赋值 | `x += y` | 左操作数的类型；结果不是左值 | 右到左 | 否；左右操作数求值顺序未规定 |
| `<<=`、`>>=`、`&=`、`^=`、`\|=` | 移位及位运算复合赋值 | `x <<= n` | 左操作数的类型；结果不是左值 | 右到左 | 否 |
| `,` | 逗号运算符 | `a, b` | 右操作数的类型和结果 | 左到右 | 是；先求值 `a`，再求值 `b` |

> 注：表中的“结合性”只决定运算符的分组方式，不决定操作数的实际求值顺序。例如 `f1() + f2()` 中，`f1()` 和 `f2()` 谁先执行通常没有规定。逗号分隔函数实参时是标点符号，不是逗号运算符，例如 `func(a, b)` 不保证先求值 `a` 再求值 `b`。
