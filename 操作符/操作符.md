# C 语言操作符

操作符（operator）是用于对一个或多个操作数进行运算、比较、赋值或访问的符号。按照操作数的数量，可以分为：

- **一元操作符**：只需要一个操作数，例如 `!a`、`++a`、`sizeof(a)`。
- **二元操作符**：需要两个操作数，例如 `a + b`、`a = b`、`a && b`。
- **三元操作符**：C 语言中唯一的三元操作符是条件操作符 `?:`。

## 一、算术操作符

算术操作符用于完成基本数学运算。

| 操作符 | 名称 | 用法 | 说明 |
|---|---|---|---|
| `+` | 加法 | `a + b` | 计算两个操作数的和，也可以作为一元正号使用，如 `+a` |
| `-` | 减法 | `a - b` | 计算两个操作数的差，也可以作为一元负号使用，如 `-a` |
| `*` | 乘法 | `a * b` | 计算两个操作数的积 |
| `/` | 除法 | `a / b` | 计算商；两个整数相除时结果仍为整数，小数部分会被舍弃 |
| `%` | 取模 | `a % b` | 计算整数相除后的余数，操作数必须是整数类型 |
| `++` | 自增 | `++a` 或 `a++` | 使操作数增加 `1` |
| `--` | 自减 | `--a` 或 `a--` | 使操作数减少 `1` |

### 前置和后置自增、自减

```c
int a = 5;
int b = ++a;  // 先使 a 变为 6，再将 6 赋给 b

int c = 5;
int d = c++;  // 先将 5 赋给 d，再使 c 变为 6
```

`++` 和 `--` 的操作数必须是可修改的左值，例如变量，不能直接用于常量：

```c
// 5++;  // 错误，常量不能被修改
```

## 二、关系操作符

关系操作符用于比较两个操作数的大小或是否相等。表达式成立时结果为 `1`，不成立时结果为 `0`。

| 操作符 | 名称 | 用法 |
|---|---|---|
| `<` | 小于 | `a < b` |
| `>` | 大于 | `a > b` |
| `<=` | 小于等于 | `a <= b` |
| `>=` | 大于等于 | `a >= b` |
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |

```c
int age = 18;
if (age >= 18) {
    printf("成年\\n");
}
```

注意：`==` 用于比较，`=` 用于赋值。把 `if (a = 1)` 写成条件判断通常是错误的，因为它会先赋值，再判断结果。

## 三、逻辑操作符

逻辑操作符通常用于组合多个条件表达式，结果为 `0` 或 `1`。

| 操作符 | 名称 | 用法 | 规则 |
|---|---|---|---|
| `!` | 逻辑非 | `!a` | `a` 为真时结果为 `0`，`a` 为假时结果为 `1` |
| `&&` | 逻辑与 | `a && b` | 两个表达式都为真时结果才为真 |
| `||` | 逻辑或 | `a || b` | 至少一个表达式为真时结果为真 |

C 语言中，`0` 表示假，非 `0` 表示真。

### 短路求值

`&&` 和 `||` 会进行短路求值：

```c
if (p != NULL && *p == 10) {
    // 只有 p 不为空时，才会计算 *p == 10
}
```

上例中，如果 `p == NULL`，右侧表达式不会执行，从而避免解引用空指针。

## 四、位操作符

位操作符直接对整数的二进制位进行操作，常用于标志位、权限、掩码和底层编程。

| 操作符 | 名称 | 用法 | 说明 |
|---|---|---|---|
| `&` | 按位与 | `a & b` | 对应位都为 `1` 时结果位才为 `1` |
| `|` | 按位或 | `a | b` | 对应位至少一个为 `1` 时结果位为 `1` |
| `^` | 按位异或 | `a ^ b` | 对应位不同时结果位为 `1` |
| `~` | 按位取反 | `~a` | 将每一位的 `0` 和 `1` 互换 |
| `<<` | 左移 | `a << n` | 将 `a` 的二进制位向左移动 `n` 位 |
| `>>` | 右移 | `a >> n` | 将 `a` 的二进制位向右移动 `n` 位 |

```c
int flags = 0;
flags = flags | (1 << 2);  // 将第 2 位设置为 1
flags = flags & ~(1 << 2); // 将第 2 位清零
```

位移操作时，右侧的位数应当是非负数，并且小于左侧操作数的位宽。对有符号负数进行右移时，具体结果可能与实现有关，使用时应特别谨慎。

## 五、赋值操作符

赋值操作符用于把右侧表达式的值保存到左侧可修改的对象中。

| 操作符 | 名称 | 等价写法 | 用法 |
|---|---|---|---|
| `=` | 简单赋值 | - | `a = b` |
| `+=` | 加后赋值 | `a = a + b` | `a += b` |
| `-=` | 减后赋值 | `a = a - b` | `a -= b` |
| `*=` | 乘后赋值 | `a = a * b` | `a *= b` |
| `/=` | 除后赋值 | `a = a / b` | `a /= b` |
| `%=` | 取模后赋值 | `a = a % b` | `a %= b` |
| `&=` | 按位与后赋值 | `a = a & b` | `a &= b` |
| `|=` | 按位或后赋值 | `a = a | b` | `a |= b` |
| `^=` | 按位异或后赋值 | `a = a ^ b` | `a ^= b` |
| `<<=` | 左移后赋值 | `a = a << b` | `a <<= b` |
| `>>=` | 右移后赋值 | `a = a >> b` | `a >>= b` |

赋值表达式本身也有值，因此可以连续赋值：

```c
int a, b, c;
a = b = c = 0;
```

左侧必须是可修改的左值，例如变量或通过指针访问的对象，不能是常量或普通表达式。

## 六、指针和地址操作符

| 操作符 | 名称 | 用法 | 说明 |
|---|---|---|---|
| `&` | 取地址 | `&a` | 获取变量 `a` 的内存地址 |
| `*` | 解引用 | `*p` | 访问指针 `p` 所指向的对象 |

注意：`&` 和 `*` 的含义取决于使用位置。它们既可以用于指针操作，也分别出现在按位与、乘法等表达式中。

```c
int value = 10;
int *p = &value; // p 保存 value 的地址
*p = 20;         // 通过 p 修改 value
```

声明指针时的 `*` 表示该变量是指针类型；表达式中的 `*` 通常表示解引用。

## 七、成员访问操作符

结构体和联合体使用成员访问操作符访问其中的成员。

| 操作符 | 名称 | 用法 | 适用情况 |
|---|---|---|---|
| `.` | 直接成员访问 | `object.member` | 对象本身是结构体或联合体变量 |
| `->` | 指针成员访问 | `pointer->member` | 指针指向结构体或联合体 |

```c
struct Student {
    int age;
};

struct Student student = {18};
struct Student *p = &student;

student.age = 19;
p->age = 20; // 等价于 (*p).age = 20
```

## 八、数组下标操作符

数组下标操作符 `[]` 用于访问数组中的元素：

```c
int numbers[3] = {10, 20, 30};
int first = numbers[0];
numbers[1] = 25;
```

下标从 `0` 开始，合法范围是 `0` 到 `数组元素个数 - 1`。越界访问会产生未定义行为。

在 C 语言中，`a[b]` 等价于 `*(a + b)`，因此指针也可以使用下标操作符。

## 九、函数调用操作符

圆括号 `()` 有两种常见用途：函数调用和改变表达式优先级。

```c
int result = add(2, 3); // 函数调用
int value = (a + b) * c; // 改变计算顺序
```

调用函数时，圆括号中可以传入参数；没有参数时也要写空括号，例如 `get_value()`。

## 十、条件操作符

条件操作符 `?:` 是 C 语言唯一的三元操作符，格式如下：

```c
条件表达式 ? 表达式1 : 表达式2
```

如果条件表达式为真，计算表达式 `1`；否则计算表达式 `2`。

```c
int max = a > b ? a : b;
```

条件操作符适合表示简单的二选一逻辑。条件复杂时，使用 `if...else` 通常更容易阅读。

## 十一、逗号操作符

逗号操作符 `,` 从左到右依次计算多个表达式，整个表达式的结果是最右侧表达式的结果。

```c
int result = (a = 1, b = 2, a + b); // result 为 3
```

逗号还常用于 `for` 循环中同时更新多个变量：

```c
for (int left = 0, right = 10; left < right; left++, right--) {
    // 循环体
}
```

函数参数之间的逗号是分隔符，不一定是逗号操作符。需要得到逗号表达式的结果时，建议使用括号明确范围。

## 十二、`sizeof` 操作符

`sizeof` 用于获取类型或对象所占的字节数，结果类型为 `size_t`。

```c
int a;
printf("%zu\\n", sizeof(a));
printf("%zu\\n", sizeof(int));
```

对于数组，`sizeof` 获取的是整个数组的大小；但数组作为函数参数传递时，通常会退化为指针：

```c
int numbers[10];
size_t count = sizeof(numbers) / sizeof(numbers[0]); // 数组元素个数
```

`sizeof` 通常不会计算其操作数表达式的值：

```c
int i = 0;
size_t size = sizeof(i++); // i 通常仍为 0
```

## 十三、类型转换操作符

类型转换使用括号指定目标类型：

```c
int total = 5;
int count = 2;
double average = (double)total / count; // 2.5
```

如果不转换，`total / count` 会先进行整数除法，结果为 `2`。

类型转换可能造成精度丢失、溢出或符号变化，应确认转换是有意且安全的。指针类型转换尤其要谨慎。

## 十四、`_Alignof` 操作符（C11）

C11 提供 `_Alignof` 操作符，用于获取类型的对齐要求，返回结果类型为 `size_t`：

```c
size_t alignment = _Alignof(double);
```

使用它需要编译器支持 C11 或更高标准。

## 十五、常见操作符优先级

下表从上到下表示优先级由高到低。优先级相同的操作符要根据结合性计算；不确定时应使用括号明确意图。

| 优先级 | 操作符 | 结合性 |
|---|---|---|
| 高 | `()` `[]` `->` `.` `x++` `x--` | 从左到右 |
|  | `++x` `--x` `+x` `-x` `!` `~` `*` `&` `sizeof` `_Alignof` | 从右到左 |
|  | `*` `/` `%` | 从左到右 |
|  | `+` `-` | 从左到右 |
|  | `<<` `>>` | 从左到右 |
|  | `<` `<=` `>` `>=` | 从左到右 |
|  | `==` `!=` | 从左到右 |
|  | `&` | 从左到右 |
|  | `^` | 从左到右 |
|  | `|` | 从左到右 |
|  | `&&` | 从左到右 |
|  | `||` | 从左到右 |
|  | `?:` | 从右到左 |
|  | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `|=` | 从右到左 |
| 低 | `,` | 从左到右 |

例如：

```c
int result = a + b * c;       // 先乘法，再加法
int clear = (a + b) * c;      // 括号改变计算顺序
int valid = a > 0 && b > 0;   // 先比较，再进行逻辑与
```

## 十六、使用操作符时的注意事项

1. 区分赋值操作符 `=` 和相等比较操作符 `==`。
2. 整数除法不会自动保留小数，需要先转换为浮点类型。
3. `&&`、`||` 具有短路求值特性，不要随意依赖复杂的副作用。
4. 不要访问数组边界之外的元素，也不要解引用空指针或野指针。
5. 不要在同一个表达式中多次修改同一个变量并依赖求值顺序，例如 `i++ + ++i`，这类写法可能导致未定义行为。
6. 位操作优先级容易和关系、逻辑操作符混淆，使用括号可以提高可读性。
7. 自增、自减和复合赋值操作符的操作数必须是可修改的左值。
8. 复杂表达式应使用括号明确意图，不要只依赖记忆中的优先级。
